# YouTube packaging and thumbnails

## English upload package

Deliver ready-to-copy English text even when the narration is Hindi. State "Hindi commentary with English subtitles" so the audience understands the language.

- Recommend one strong title with the main search term near the beginning and a clear curiosity hook. Keep it faithful to the actual content. Do not convert reports into "confirmed features," call commentary a hands-on review, or guarantee click-through/search ranking.
- Write the description's first two lines around the video's actual value. Follow with a concise topic summary, actual chapters, a relevant viewer question, subscribe invitation, date/scope context when material, and real source credits.
- Generate chapter timestamps from the final timeline. Start at 00:00 and follow current YouTube chapter rules. Never copy another video's chapter times or use draft-script timing after retiming the edit.
- Separate comma-separated tags from the public description. Use relevant topic/title variations within the current platform limit; avoid unrelated trending keywords or repetitive keyword blocks.
- Put a small set of relevant hashtags at the end of the description. Keep all explanatory prose and thumbnail copy in English; a relevant tag such as GTA6Hindi can still identify the spoken language.
- Verify volatile dates, platform announcements and official claims from primary sources before introducing them into new marketing copy. Do not imply a fresh factual review merely because the user accepted the edit.
- Attribute actual source owners and specific videos when known. Attribution does not prove reuse permission. Do not add a generic legal disclaimer promising copyright protection.

## Thumbnail concept selection

For a new thumbnail direction, the user liked choosing from **six distinct prototypes** before final refinement. Follow that when they request a concept-selection stage; do not regenerate six for a narrow revision or when an approved direction already exists.

- Use the available image-generation tool for raster artwork and edits. If its imagegen skill is available, follow it. Do not replace a requested generated thumbnail with a code-drawn placeholder.
- Make each concept a separate image with a distinct composition or hook. Label concepts clearly in the response so the user can select by number. Keep foreground text short and readable at mobile size.
- Preserve the selected references during revisions. Inspect local reference images before using them; distinguish visual-style reference from text/layout reference. Use reference-image edit inputs rather than relying only on a verbal recollection.
- For the established GTA video, the chosen synthesis was **prototype 1's characters, sunset background and typography + prototype 3's giant "100 DETAILS" hierarchy**. Visual cues: coral/pink sunset, deep navy shadows, tropical palms, waterfront skyline, neon pink accents, cinematic character lighting and a sports car. White "100", pink "DETAILS", and a GTA 6 identifier. This is a preference for that gaming topic, not a requirement to put GTA branding on unrelated videos.
- The user wants a coherent game-specific premium appearance across subjects, lettering and background. Avoid unrelated generic stock styling, cluttered badges, fake gameplay HUDs, fabricated mechanics or a invented presenter facecam. Treat generated scenes as editorial key art, not proof of gameplay.
- Keep key text clear of the lower-right duration badge and inside safe margins. Inspect wording, faces, hands, logo-like lettering, contrast and overall crop. Confirm actual pixel dimensions rather than assuming the generator honored a size request.
- Save selected deliverables and their prompt/reference provenance in the workspace under versioned filenames. Check current YouTube thumbnail format, dimensions and file-size requirements before claiming a file is upload-ready; produce a suitable delivery copy when needed while preserving the original.
